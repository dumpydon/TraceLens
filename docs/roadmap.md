# Roadmap

The roadmap separates working V1 behavior from intentionally unimplemented directions. Future
items are documentation only and have no placeholder subsystems in the repository.

## V1 COMPLETE

- Executable checkout and payment lab with five deterministic scenarios
- Correlated structured request logs, deployment metadata, and health evidence
- Explicit bounded LangGraph investigation with typed structured outputs
- Persistent SQLite checkpoints, reports, events, and evaluation summaries
- Persistent Chroma MMR retrieval over focused operational knowledge
- Semantic SSE investigation streaming and an engineer-facing Next.js UI
- Optional LangSmith tracing and a reproducible offline evaluation harness

## PHASE 2

- Human-in-the-loop approval using LangGraph interrupts
- Retrieval strategy benchmarks against a similarity baseline
- MultiQueryRetriever and ContextualCompressionRetriever experiments
- Corrective RAG experiments
- Git repository integration for real commit and diff inspection
- An MCP boundary for Incident Lab or Git operations where it creates a clean external contract

## PHASE 3

- Prometheus metrics and OpenTelemetry traces
- Grafana integration
- Dockerized multi-service lab and additional failure scenarios
- Specialized subgraphs for distinct investigation domains
- Human-reviewed remediation proposals and approved rollback workflows

## LONG TERM

- Postgres-backed production persistence
- Real external incident and observability integrations
- Formal retrieval benchmarks and calibrated confidence research
- Security, authentication, tenancy, and operational controls required for a deployed service
